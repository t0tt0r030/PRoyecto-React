# Información de proyecto 'Pastelería Mil Sabores'

Este proyecto está conformado por la librería React, que corresponde solo a la parte 
de Front-End.
Este documento detalla la instalación de dependencias para que este proyecto pueda funcionar de forma óptima.

## Instalación de dependencias

Este proyecto contempla los siguientes comandos para su correcto funcionamiento:

### `npm install`

Instala todas las dependencias y modulos base para que pueda correr el sistema.

### `npm install bootstrap`

Dependencia destinada a los estilos de página.

### `npm install lucide-react`

Dependencia destinada a los íconos del sistema.

### `npm install react-router-dom`

Permite crear las rutas de direccionamiento del sistema (/login, /header, /productos)

### `npm install swiper`

Permite la visualización tipo 'carroucel' dentro del sistema
